# Yuvis音乐

一款以“一点红”为视觉线索的 Windows 本地音乐播放器。音乐文件、收藏和播放记录均保留在本机。

## 功能

- 导入单个或多个音频文件，也可递归扫描整个文件夹
- 自动读取标题、艺术家、专辑、时长与内嵌封面
- 启动时复用未变化歌曲的元数据缓存，并按需加载封面与歌词
- 音乐库搜索、标题排序、收藏和最近播放
- 音乐库、收藏、歌单内歌曲、左侧歌单和当前播放队列支持鼠标拖动排序，显示插入位置并在列表边缘自动滚动；按 Esc 取消拖动
- 拖动时整行抬起并平滑跟随鼠标，其他条目动画让位，放下或取消时平滑归位；兼容系统的减少动态效果设置
- 拖动歌曲后自动切换为手动排序，也可选择标题升序 / 降序；音乐库、收藏及歌单顺序自动保存，搜索时只调整匹配歌曲的位置，播放队列调整立即影响后续播放且不会中断当前歌曲
- 沉浸式正在播放页面，实时同步封面、进度与播放状态
- 播放页使用香槟暖白与雾蓝渐变、细腻纹理及柔光背景，移除 NOW PLAYING 标识；两种唱片样式与原版全屏歌词共用背景
- 播放页右上角可切换样式一（原版封面与侧面唱片）和样式二（封面嵌入唱片一起旋转）；暂停时停转，选择自动保存，普通页与全屏歌词页共用
- 自动读取音频内嵌歌词和同名 LRC/TXT 歌词文件
- 支持手动指定歌词文件、LRC 时间轴高亮与点击歌词跳转
- 歌词逐帧跟随播放时钟，当前行以主题红即时高亮并居中
- 透明置顶桌面歌词，支持双层歌词、四种显示样式与主副歌词颜色设置
- 桌面歌词提供纯文字模式，播放页支持按歌曲保存歌词提前/延后微调
- 桌面歌词支持点击显示窗口范围、锁定位置与锁定状态下右击解锁
- 游戏歌词锁定后鼠标完全穿透，不接收鼠标移动或显示歌词光标；默认按 `Ctrl+R` 切换锁定 / 解锁，支持后台使用，也可在“设置 → 歌词 → 游戏歌词”关闭锁定，恢复拖动和右键菜单
- 歌单自动使用歌曲封面拼贴，无封面时显示浅色主题缩略图
- 全局使用更易读的放大字号层级，兼顾标准窗口与窄窗口
- 自定义歌单创建、歌曲添加、歌单浏览与删除
- 播放队列、随机播放、列表循环与单曲循环；随机播放仅从当前播放队列选曲，多首时避开当前歌曲，队列清空后不会从音乐库补歌
- 进度拖动、音量、静音、上一首和下一首
- 标题栏内置十段声音均衡器，支持实时调节、内置音效、恢复默认以及自定义方案保存和删除
- 通用设置中心，音量、静音、播放模式与桌面歌词设置均会自动保存并在下次启动恢复
- 设置按播放、快捷键、歌词、外观、存储与性能、AI 助手分类；歌词页内切换桌面 / 游戏 / 全屏歌词，播放页分为声音、播放方式、启动与恢复
- 自动记住当前歌曲、播放进度和队列顺序，下次启动后恢复并保持暂停；播放中每 5 秒保存进度，暂停、跳转及关闭时立即保存。已清空的队列保持为空，无法读取的歌曲在本次恢复中跳过，已播完的歌曲从头待播；恢复本身不增加播放记录或聆听次数
- 统计面板分为聆听概览、音乐库分析和歌单概览；可筛选今天、近 7 / 30 / 365 天及全部记录，查看时长 / 播放次数趋势、歌曲 TOP 10、活跃天数、日均与最高单日聆听
- 音乐库统计展示艺术家、专辑、文件格式、时长分布及收藏占比；歌单统计展示收录数量、乐库覆盖率、空歌单和当前乐库未收录的条目
- 快捷键可在设置中心录入自定义组合键，支持后台控制、开启或关闭游戏歌词、冲突校验、后台注册状态提示、一键恢复默认与键盘媒体控制键
- 外观设置提供小、标准、大、超大四档字体大小；只调整文字而不缩放面板和布局，选择后立即生效并自动保存
- Yuvis 助手可查询音乐库、歌词、播放记录与统计，并通过工具调用控制播放、队列、收藏、歌单和桌面歌词
- “设置 → AI 助手”支持自定义模型名称、OpenAI Chat Completions 兼容地址与 API Key；密钥仅由主进程读取并优先使用系统加密保存
- 填写模型地址和 API Key 后可点击“获取模型”，从服务返回的模型列表中选择，也可直接填写模型名；密钥留空时沿用已保存的密钥，获取列表不会自动保存配置
- 标题栏提供 AI 对接文档、快捷键和独立关于页面；关于页面展示软件介绍、版本、平台、隐私理念及制作人信息
- AI 对接文档按功能分组展示当前版本全部工具接口、参数类型和安全边界
- 左侧菜单与右侧功能区采用统一圆角卡片布局，播放详情页展开时保持边界一致
- 自绘融合式标题栏，提供主题化的最小化、最大化/还原和关闭按钮
- 支持 MP3、FLAC、WAV、M4A、AAC、OGG、OPUS、WMA

## 本地开发

```powershell
npm install
npm start
```

默认快捷键：`Ctrl+←` 上一曲，`Space` 播放/暂停，`Ctrl+→` 下一曲，`Ctrl+K` 打开播放器并聚焦搜索，`Ctrl+Alt+Shift+L` 开启或关闭游戏歌词（隐藏时开启、显示时关闭，锁定时也可使用），`Ctrl+R` 锁定 / 解锁游戏歌词；可在“设置 → 快捷键”中自定义，同时支持键盘媒体控制键。

播放器在后台或最小化时，播放/暂停使用 `Ctrl+Alt+Space`，其余默认组合键保持一致。自定义的单独空格、字母等按键在后台会加上 `Ctrl+Alt`，以保留其他软件的正常输入。设置页和快捷键页面显示对应的后台组合键；被其他软件占用或不支持后台使用时，设置页会提示更换组合键。切回播放器后继续使用页面快捷键，保留输入框编辑和组合键录入行为。

## Windows 打包

```powershell
npm run icon
npm run build
npm run build:portable
```

安装包会输出到 `dist/1.1.0/Yuvis-Music-1.1.0-x64.exe`，使用系统级安装并在 Windows“控制面板 → 程序和功能”中注册卸载入口。

推荐便携版会输出到 `dist/1.1.0/Yuvis-Music-1.1.0-x64-Portable.zip`。解压后运行其中的 `Yuvis音乐.exe`，不会安装或写入控制面板；ZIP 方案不使用容易触发杀毒软件启发式检测的 NSIS 自解压外壳，也不包含播放器不需要的提权辅助程序。若因兼容需求仍要生成旧式单文件版本，可执行 `npm run build:portable:single-exe`，但不建议公开分发未签名的单文件自解压包。

## 修改留档

每次完成一组修改后运行：

```powershell
npm run checkpoint -- "本次修改说明"
```

该命令会依次检查源码、生成安装包与便携版、提交 Git、创建带时间的标签，并将两个 EXE 与校验信息保存到 `releases/` 下的独立时间目录。最新归档位置记录在 `releases/LATEST.txt`。
