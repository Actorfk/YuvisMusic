# Yuvis音乐

一款以“一点红”为视觉线索的 Windows 本地音乐播放器。音乐文件、收藏和播放记录均保留在本机。

## 功能

- 导入单个或多个音频文件，也可递归扫描整个文件夹
- 自动读取标题、艺术家、专辑、时长与内嵌封面
- 音乐库搜索、标题排序、收藏和最近播放
- 沉浸式正在播放页面，实时同步封面、进度与播放状态
- 自动读取音频内嵌歌词和同名 LRC/TXT 歌词文件
- 支持手动指定歌词文件、LRC 时间轴高亮与点击歌词跳转
- 歌词逐帧跟随播放时钟，当前行以主题红即时高亮并居中
- 透明置顶桌面歌词，支持双层歌词、四种显示样式与主副歌词颜色设置
- 桌面歌词提供纯文字模式，播放页支持按歌曲保存歌词提前/延后微调
- 桌面歌词支持点击显示窗口范围、锁定位置与锁定状态下右击解锁
- 歌单自动使用歌曲封面拼贴，无封面时显示浅色主题缩略图
- 全局使用更易读的放大字号层级，兼顾标准窗口与窄窗口
- 自定义歌单创建、歌曲添加、歌单浏览与删除
- 播放队列、随机播放、列表循环与单曲循环
- 进度拖动、音量、静音、上一首和下一首
- 标题栏内置十段声音均衡器，支持实时调节、内置音效、恢复默认以及自定义方案保存和删除
- 通用设置中心，音量、静音、播放模式与桌面歌词设置均会自动保存并在下次启动恢复
- 外观设置提供小、标准、大、超大四档字体大小；只调整文字而不缩放面板和布局，选择后立即生效并自动保存
- Yuvis 助手可查询音乐库、歌词、播放记录与统计，并通过工具调用控制播放、队列、收藏、歌单和桌面歌词
- Yuvis 配置支持自定义模型名称、OpenAI Chat Completions 兼容地址与 API Key；密钥仅由主进程读取并优先使用系统加密保存
- 标题栏提供 AI 对接文档、快捷键和独立关于页面；关于页面展示软件介绍、版本、平台、隐私理念及制作人信息
- AI 对接文档按功能分组展示当前版本全部工具接口、参数类型和安全边界
- 左侧菜单与右侧功能区采用统一圆角卡片布局，播放详情页展开时保持边界一致
- 自绘融合式标题栏，提供主题化的最小化、最大化/还原和关闭按钮
- 支持 MP3、FLAC、WAV、M4A、AAC、OGG、OPUS、WMA

## 本地开发

```powershell
npm install
npm start
```

快捷键：`Ctrl+←` 上一曲，`Space` 播放/暂停，`Ctrl+→` 下一曲，`Ctrl+K` 聚焦搜索；同时支持键盘媒体控制键。

## Windows 打包

```powershell
npm run icon
npm run build
```

安装包会输出到 `dist/Yuvis-Music-1.0.0-x64.exe`。如只需要免安装目录，可执行 `npm run pack`。

## 修改留档

每次完成一组修改后运行：

```powershell
npm run checkpoint -- "本次修改说明"
```

该命令会依次检查源码、生成安装包与便携版、提交 Git、创建带时间的标签，并将两个 EXE 与校验信息保存到 `releases/` 下的独立时间目录。最新归档位置记录在 `releases/LATEST.txt`。
